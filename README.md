# FrameNest

A decentralized photo collection management system built on Stacks blockchain. This contract handles photo collection storage, management and sharing capabilities.

## Features
- Store photo collection metadata on-chain
- Create and manage albums
- Share collections with other users
- Set permissions for viewing and editing
- Transfer collection ownership
- Track collection statistics
- Secure deletion of collections

## Functions
### Management
- `create-collection`: Create a new photo collection
- `transfer-collection`: Transfer ownership to another user
- `delete-collection`: Remove a collection
- `add-photo`: Add a photo to a collection

### Permissions
- `set-permissions`: Set user permissions for a collection
- `get-permissions`: View user permissions

### Statistics
- `get-collection-stats`: View collection statistics
